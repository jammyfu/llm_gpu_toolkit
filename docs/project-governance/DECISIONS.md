# DECISIONS.md

## 2026-11-17

- Treat yarn as the web app package manager because `.github/workflows/static.yml` runs `yarn install` / `yarn build` in `llm-vram-calc-web`. Keep both `yarn.lock` and `package-lock.json` generated by their package managers so npm audit and yarn stay aligned.
- Pin `nth-check` to 2.1.1, not 3.0.1: 2.1.1 is the last CommonJS release that still satisfies CRA's `css-select@2.1.0`. `nth-check@3` is ESM-only (`type: module`, `boolbase@^2`, Node `>=20.19.0`) and would break that path.
- Pin `postcss` to 8.5.33, not the screenshot floor of 8.4.31. Official advisories after 8.4.31 still affect `<=8.5.22` (GHSA-qx2v-qp2m-jg93, GHSA-6g55-p6wh-862q, GHSA-fxqj-rqcc-2cmp, GHSA-r28c-9q8g-f849). Also pin `nanoid@3.3.20` and `source-map-js@1.2.2` because they are the postcss 8 runtime deps currently flagged on the same path.
- Pin `webpack-dev-server` to 5.2.7 (latest 5.x), not 5.2.1. GHSA-4v9v-hfq4-rm2v / GHSA-9jgg-88mc-972h are fixed in 5.2.1; later 2026 advisories require 5.2.6+. Do not jump to 6.1.0: it needs webpack `^5.101.0` and Node `>=22.15.0`, which is a CRA migration.
- CRA 5 still emits `https` / `onBeforeSetupMiddleware` / `onAfterSetupMiddleware`. Keep `react-scripts@5.0.1` and apply a minimal `patch-package` mapping those options to webpack-dev-server 5 `server` / `setupMiddlewares`. Verified with `yarn start` compiling and serving HTTP 200.
- Do not hide remaining CRA 5 toolchain advisories (`svgo@1`, `websocket-driver` via sockjs, `ws` 8.20.1, `proxy-addr`, etc.). They need a bundler migration, not `npm audit --force` onto `react-scripts@0.0.0`.
