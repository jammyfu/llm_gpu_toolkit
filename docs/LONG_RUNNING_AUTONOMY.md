# LONG_RUNNING_AUTONOMY.md

## Operating Rules

- Start from `AGENTS.md`, `PROJECT_BRIEF.md`, and `CURRENT_PLAN.md`.
- Complete one small, verifiable slice per cycle.
- Record execution in `docs/project-governance/WORKLOG.md`.
- Move non-current work into `TODO_BACKLOG.md`.

## Repo-Specific Guidance

- Favor clarity about assumptions over speculative optimizations.
- Keep web and data responsibilities separated in planning.
- Promote repeatable checks before adding features.
